# Личная проверка перед сдачей

Автоматические проверки выполнил coding agent. Курс отдельно требует вашу
собственную проверку результата и объяснение своими словами. Её выполнение
не заявляется заранее и не подменяется согласованием плана.

После реальных экспериментов откройте `exam/results/examples.json`:

1. Выберите одного из двух пользователей и один метод.
2. Выпишите actual Top-5 и ranked prediction Top-5 по ID.
3. Отметьте позиции уникальных совпадений.
4. Рассчитайте precision на каждой такой позиции; сложите и разделите на 5.
5. Сопоставьте число с `ap5` для этого пользователя и метода.
6. Запишите в `private/my_check.txt`, какие ID, позиции и дроби вы проверили,
   совпал ли результат и какие остальные выводы вы самостоятельно не проверяли.

Пример формулы, **не эксперимент на данных соревнования**:
actual `{1,2,3,4,5}`, predicted `[1,2,9,3,4]`:
`AP@5 = (1/1 + 2/2 + 3/4 + 4/5)/5 = 0.71`.

В итоговом отчёте должно стоять ваше утверждение о реально выполненной проверке,
а не формулировка помощника «студент лично проверил» без такого действия.
