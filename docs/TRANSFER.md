# Передача подготовленного проекта

25.10.2026 запись через текущее подключение GitHub была отклонена:
`403 Resource not accessible by integration` как для Git Trees API,
так и для Contents API. Публичное чтение работает; права владельца аккаунта
не означают, что подключению разрешена запись. Ни один файл этим подключением
в репозиторий не записан.

Нужно подключение с правом записи Contents в `kiraafa03-svg/ML-and-rec-sys-`.
После настройки можно опубликовать подготовленный commit. Токен не является
частью проекта и не должен добавляться в его файлы.

Архив содержит исходники и `repository.bundle` с полной подготовленной
историей Git, включая исходный пользовательский commit. Bundle не требует
доступа к рабочему облачному контейнеру.

Из каталога распакованного архива:

```bash
git clone repository.bundle local-repo
cd local-repo
git remote set-url origin https://github.com/kiraafa03-svg/ML-and-rec-sys-.git
git push -u origin main
```

Push выполняется с авторизацией локального GitHub-клиента. Force push не нужен.
Если исходная удалённая ветка успела измениться, обычный push отклонится;
сначала получите и согласуйте изменения, не перезаписывая их.

Для экспериментов после настройки Kaggle и скачивания данных:

```bash
python scripts/run_local.py --data-dir exam/data
```

Синтетический PDF использовался только для внутренней проверки вёрстки и в
архив не включён. Экзаменационный PDF и private score не заявлены полученными.
