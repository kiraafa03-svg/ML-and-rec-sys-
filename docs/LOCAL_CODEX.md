# Локальный запуск и журнал Codex

Текущая рабочая сессия выполняется в облачном Linux-контейнере. Она не может
запускать процессы на компьютере владельца аккаунта. Разрешение на локальный
запуск не создаёт техническое подключение к этому компьютеру.

Для локального выполнения:

1. Откройте репозиторий в установленном локальном Codex/терминале.
2. Создайте `.venv`, установите зависимости из README.
3. Авторизуйте Kaggle штатной командой `kaggle auth login`, примите Rules.
4. Скачайте пять исходных CSV и запустите `python scripts/run_local.py`.
5. Проверьте `exam/results/verification.json`, отправьте final.csv на Kaggle.

Официальное различие Local/Cloud:
https://learn.chatgpt.com/docs/environments/modes

## Исходный экспорт

Курс принимает оригинальный Codex CLI rollout/JSONL или штатный экспорт другого
coding agent, сохраняющий запросы, сгенерированный код и результаты инструментов.
В этой облачной среде такого файла нет, и экспорт через доступные инструменты
не предоставлен. Поэтому файл с реконструированным разговором не создаётся.

При локальной работе сохраните оригинальный rollout своей сессии из каталога
сессий установленного Codex. Точное расположение зависит от локальной установки
и её настройки CODEX_HOME. Скопируйте файл без фильтрации и преобразования:

```bash
python scripts/copy_native_session.py PATH_TO_ACTUAL_ROLLOUT private/original_session.jsonl
```

Копия сверяется побайтово. Проверка структуры не подтверждает, что произвольный
файл действительно относится к работе: соответствие проверяется по содержимому
самого исходного журнала. Облачная помощь должна быть раскрыта отдельно; более
поздний локальный журнал не доказывает события, которых в нём нет.

Официальная документация JSONL-событий Codex CLI:
https://learn.chatgpt.com/docs/non-interactive-mode

`codex exec --json` может дополнительно сохранять машинные события нового
запуска. Не подменяйте ими отсутствующие запросы/события исходной сессии.
JSON со ссылкой на чат является только указателем; это не требуемый audit trail.
